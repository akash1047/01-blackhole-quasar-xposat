## How the pieces fit

```
galaxy gas  →  accretion disk  →  hot corona / UV disk  →  enormous luminosity
                     ↓
            supermassive black hole (the engine, not the lamp)
                     ↓
                 jets / winds  →  feedback into the host galaxy
```

A **black hole** is the compact engine. A **quasar** is what you get when that engine is fed so hard that the *surrounding* disk and corona outshine the entire host galaxy.

Illustrations in `figures/wiki/` are teaching art, not telescope data.

The X-ray page is the bridge to XPoSat (POLIX polarimetry ~8–30 keV, XSPECT spectroscopy ~0.8–15 keV) and to the Crab L2 notes.
